# 嘉采商家订货小程序

原生微信小程序，商品、单位、销售价和客户专属名称均读取现有 FastAPI 系统。商家下单后直接生成或合并现有销售单，并继续参与采购、仓库、分拣和财务联动。

## 首次配置

1. 在微信公众平台注册“小程序”，取得 AppID 和 AppSecret。
2. 在服务器 `backend/.env` 增加（不要提交 Git）：

   ```env
   MINI_PROGRAM_APP_ID=你的AppID
   MINI_PROGRAM_APP_SECRET=你的AppSecret
   ```

3. 重启后端服务。
4. 使用微信开发者工具导入本目录，把 `project.config.json` 的 `appid` 改为真实 AppID。
5. 开发阶段可在开发者工具中勾选“不校验合法域名”。正式发布前，把 `config.js` 改成已备案的 HTTPS 域名，并在微信公众平台把该域名配置为 `request` 合法域名。
6. 后台“客户管理”必须填写唯一客户编号和预留手机号，商家首次进入时用二者绑定。

## 价格与安全

小程序只提交商品、单位和数量，最终价格由服务器在下单瞬间重新读取。前端缓存价格被修改也不会影响销售单金额。同一客户、同一配送日的加单会合并到同一张销售单。
